Gesonderte Fachkorrekturen

Diese Abweichungen sind in den betreffenden Webvarianten markiert. Die Originale bleiben unverändert. Technische Originaldokumentation geprüft am 28.09.2026.

K1

Link und Button

HTML Teil 2, S. 20–21

Kein button innerhalb eines Links. Der Link wird direkt gestaltet.

Technische Originaldokumentation
K2

Kaskade

CSS Teil 1, S. 18/41

Internes CSS gewinnt nicht pauschal gegen externes. Die Beispiele grenzen Herkunft, Wichtigkeit und Ebene ein; dann werden Spezifität und Quellreihenfolge verglichen.

Technische Originaldokumentation
K3

Cover/Contain

CSS Teil 2, S. 14

Cover erhält bei natürlichem Seitenverhältnis dieses Verhältnis. Ein Ausschnitt kann fehlen; contain kann freie Fläche lassen. Prozentwerte beziehen sich auf den Hintergrund-Positionierungsbereich.

Technische Originaldokumentation
K4

Operatoren und Syntax

PHP, S. 15–20

.= hängt rechts an; = weist zu. Die ausführbaren Schleifen/Funktionen ergänzen fehlende Dollarzeichen, Anführungszeichen und Semikolons.

Technische Originaldokumentation
K5

Parameter statt SQL-Verkettung

PHP, S. 30–31

Der Formularwert wird gebunden. Eingabeprüfung und Ausgabeformatierung bleiben eigene Schritte.

Technische Originaldokumentation
K6

Leere Elemente

HTML Teil 1, S. 11

Bei leeren Elementen in HTML ist ein Schrägstrich am Ende des Start-Tags nicht erforderlich. End-Tags werden nicht ergänzt.

Technische Originaldokumentation
K7

Bezeichner

HTML Teil 1, S. 23; CSS Teil 1, S. 24

Mit einem Buchstaben zu beginnen ist unsere einfache Kurskonvention. HTML verbietet einen Ziffernstart nicht allgemein; die direkte Verwendung in CSS kann besondere Schreibweisen benötigen.

Technische Originaldokumentation
K8

UTF-8

HTML Teil 1, S. 25

UFT-8 ist ein Schreibfehler; das folgende Codebeispiel der Vorlage verwendet bereits UTF-8.

Technische Originaldokumentation
K9

DOM und PHP

HTML Teil 1, S. 27

PHP erzeugt hier serverseitig eine Antwort. Eine Manipulation des lebenden Browser-DOM ist nicht unmittelbar eine PHP-Ausführung; dafür dient clientseitige Werkzeuglogik.

Technische Originaldokumentation
K10

Semantische Container

HTML Teil 2, S. 5/10

main darf den zentralen Suchbereich einer Suchseite enthalten. div kann nicht beliebig in jedes andere Element verschachtelt werden; die Inhaltsmodelle gelten weiterhin.

Technische Originaldokumentation
K11

Formularzuordnung

HTML Teil 2, S. 23

Formulargebundene Elemente können über das form-Attribut auch außerhalb zugeordnet werden. Die Grundlagenbeispiele verwenden bewusst die einfache Verschachtelung.

Technische Originaldokumentation
K12

Groß-/Kleinschreibung

CSS Teil 1, S. 24

Im normalen HTML-Standards-Modus werden ID- und Klassennamen nicht pauschal unabhängig von Groß-/Kleinschreibung verglichen.

Technische Originaldokumentation
E1

HTML-Maskierung

Ergänzung zur PHP-Ausgabe

htmlspecialchars wird für HTML-Text und quotierte HTML-Attribute verwendet. Kein Ersatz für SQL-Parameterbindung, keine Passwortvalidierung.

Technische Originaldokumentation

Bewusste Grenzen

Historische Marktgrafiken, damalige Entwicklungsstände und Normfassungen werden nicht als aktuelle Kennzahlen gelehrt. Das Qualitätsmodell und „valuable“ folgen der Begriffswahl der Unterlage. Das Projekt bietet eine Suchstrecke, nicht Anmeldung oder Buchungsabschluss. Die PHP-Grundlagenfragen setzen keine Sessions, eigenen Klassen oder Passwortprüfung voraus.

Quiz-Tool und Vorlagen

Das Webgrundlagen-Layout wurde als Datei aus der Bibliothek übernommen und als visuelle Referenz ausgewertet. Der Rohdateizugriff auf den vorhandenen Quizstand war nicht verfügbar. Deshalb ist das mitgelieferte Quiz eine neu implementierte, lokal nutzbare PHP-Fassung nach dessen Bedienkonzept und JSON-Schema – keine behauptete unveränderte Kopie. Die neuen Pools wurden in dieser Fassung getestet. Ein Laufzeittest im alten Originaltool ist nicht erfolgt.
