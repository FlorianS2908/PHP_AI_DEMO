Variablen, Zuweisung und Zeichenketten

Variablen beginnen mit $. Korrektur K4: = weist einen Wert zu; . verbindet Zeichenketten und .= hängt rechts an.

  • == vergleicht Werte unter den Vergleichsregeln von PHP.
  • === berücksichtigt Wert und Typ.
  • Vollständige Anweisungen enden im Beispiel mit Semikolon.
Beispiel lesen
$anzahl = 2;
$text = "Paris";
$text .= " für " . $anzahl . " Personen";
echo $text;
Merke / Beobachtung: Ausgabe: Paris für 2 Personen. Die Operatorentabelle der Unterlage wurde hierzu ausdrücklich korrigiert.

If, elseif, else und ternärer Ausdruck

Eine Bedingung bestimmt, welcher Zweig ausgeführt wird. Bei einer Kette wird der erste zutreffende Zweig genommen.

  • Vergleiche die Werte schrittweise.
  • Der else-Zweig deckt den verbleibenden Fall ab.
  • Ein ternärer Ausdruck wählt einen von zwei Werten.
Beispiel lesen
$personen = 3;
if ($personen === 1) {
  echo "Einzelreise";
} elseif ($personen <= 4) {
  echo "Kleine Gruppe";
} else {
  echo "Große Gruppe";
}
$text = $personen > 1 ? "Mehrere" : "Eine Person";
Merke / Beobachtung: Ausgabe des if-Blocks: Kleine Gruppe. Wert von $text: Mehrere.

Switch und break

switch wählt einen passenden case. break beendet in diesem Beispiel die Fallbehandlung; ohne break kann der folgende Code ebenfalls ausgeführt werden.

  • Prüfe den Ausgangswert vor der Fallauswahl.
  • default behandelt Werte ohne passenden case.
  • Verwechsle die Fallauswahl nicht mit einer Schleife.
Beispiel lesen
$ziel = "Rom";
switch ($ziel) {
  case "Paris": echo "Frankreich"; break;
  case "Rom": echo "Italien"; break;
  default: echo "Unbekannt";
}
Merke / Beobachtung: Ausgabe: Italien.

While und do-while

while prüft vor dem Schleifenkörper. do-while führt den Körper vor der ersten Bedingungsprüfung aus. Die fehlerhaften Syntaxfragmente der Unterlage sind in K4 dokumentiert.

  • Notiere Startwert, Bedingung, Körper und Änderung.
  • Ein fehlendes Hochzählen kann eine Endlosschleife verursachen.
  • do-while kann den Körper auch bei anfangs falscher Bedingung einmal ausführen.
Beispiel lesen
$i = 3;
while ($i < 3) { echo $i; $i++; }
echo " / ";
do { echo $i; $i++; } while ($i < 3);
Merke / Beobachtung: Ausgabe: / 3. while führt hier keinen Durchlauf aus, do-while einen.

For und foreach

for bündelt Initialisierung, Bedingung und Änderung. foreach durchläuft die Einträge einer vorhandenen Sammlung.

  • Bei for die Grenze genau lesen: < ist nicht <=.
  • foreach liefert hier jeweils den Wert eines Array-Eintrags.
  • Für Codeverständnis jeden Durchlauf mit Zwischenwerten notieren.
Beispiel lesen
for ($i = 1; $i <= 3; $i++) { echo $i . " "; }
$ziele = ["Paris", "Rom"];
foreach ($ziele as $ziel) { echo $ziel . " "; }
Merke / Beobachtung: Ausgabe: 1 2 3 Paris Rom (mit Leerzeichen).

Funktionen mit Rückgabewert

Eine Funktion bündelt einen Verarbeitungsschritt. Parameter nehmen Eingabewerte auf; return liefert ein Ergebnis an den Aufrufer.

  • Berechnung und HTML-Ausgabe lassen sich trennen.
  • Benenne Funktionen nach ihrer Aufgabe.
  • Die Unterlage nennt daneben Array-, String-, Datum-, Datei- und mathematische Funktionen.
Beispiel lesen
function gesamtpreis($preisCent, $personen) {
  return $preisCent * $personen;
}
$summe = gesamtpreis(12500, 3);
echo $summe;
Merke / Beobachtung: Ausgabe: 37500. Die Cent-Rechnung ist ein didaktisches Beispiel.

GET und POST lesen

Formularnamen werden zu Schlüsseln in $_GET beziehungsweise $_POST. Die Verarbeitung muss auch ohne übermittelte Werte verständlich reagieren.

  • Prüfe die Anfrageart und fehlende Angaben.
  • E1: HTML-Ausgabe von Nutzereingaben wird passend maskiert; das ist ausdrücklich ergänzter Schutz, keine Passwortprüfung.
  • Sessions, eigene Klassen und Anmeldung gehören nicht zu diesem Grundlagenpool.
Beispiel lesen
$roh = $_POST["ziel"] ?? "";
$ziel = is_string($roh) ? trim($roh) : "";
echo htmlspecialchars($ziel, ENT_QUOTES, "UTF-8");
Merke / Beobachtung: Die vollständige POST-Demo und ein GET-Beispiel sind als PHP-Dateien enthalten.
