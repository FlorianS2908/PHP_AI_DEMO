Baustein 09 · CSS und Selektoren

CSS trennt Inhalt und Darstellung

HTML gliedert die Informationen. CSS legt visuelle Eigenschaften und Layout fest. Eine CSS-Regel verbindet einen Selektor mit einem Deklarationsblock.

  • Selektor: Welche Elemente?
  • Eigenschaft: Was wird gestaltet?
  • Wert: Welche Ausprägung wird verwendet?
Beispiel lesen
p {
  color: navy;
  background-color: lightblue;
}
Merke / Beobachtung: p ist der Selektor; color und background-color sind Eigenschaften.

Drei Wege zur CSS-Einbindung

Die Unterlage unterscheidet externes Stylesheet, internes style-Element und Inline-Deklarationen.

  • Externes CSS kann mehrere Seiten gemeinsam gestalten.
  • Internes CSS gehört im Kurs in den head einer Seite.
  • Inline-CSS betrifft ein einzelnes Element und erschwert gemeinsame Änderungen.
Beispiel lesen
<!-- im head -->
<link rel="stylesheet" href="style.css">

/* in style.css */
h1 { color: navy; }
Merke / Beobachtung: Das link-Element bindet CSS ein; es ist kein sichtbarer Navigationslink.

Baustein 09 · CSS und Selektoren

Element, Klasse, ID, Gruppe

Ein Elementselektor spricht einen Typ an. Punkt und Hash kennzeichnen Klassen- und ID-Selektoren. Mit Kommas werden Selektoren gruppiert.

  • Eine Klasse kann mehrere Elemente verschiedener Typen ansprechen.
  • Ein Element kann mehrere Klassen besitzen.
  • Korrektur K12: ID- und Klassennamen sind im normalen HTML-Standards-Modus nicht pauschal unabhängig von Groß-/Kleinschreibung.
Beispiel lesen
p { color: navy; }
.hinweis { background-color: lightblue; }
#start { font-weight: bold; }
h1, h2 { color: darkblue; }
Merke / Beobachtung: hinweis und Hinweis werden im Kurs nicht als derselbe Klassenname verwendet.

Beziehungen mit Kombinatoren ausdrücken

Leerzeichen, >, + und ~ sprechen unterschiedliche Beziehungen im Dokument an.

  • main p: passende Nachkommen auf beliebiger Tiefe.
  • main > p: direkte p-Kinder.
  • h2 + p: direkt nachfolgender p-Geschwisterknoten; h2 ~ p: passende nachfolgende Geschwister.
Beispiel lesen
<main>
  <p>Direktes Kind</p>
  <article><p>Tieferer Nachkomme</p></article>
</main>

main > p { border: 2px solid navy; }
Merke / Beobachtung: Nur der erste Absatz wird von main > p erfasst.

Kaskade und Spezifität richtig einordnen

Korrektur K2: Internes CSS gewinnt nicht automatisch gegen externes. Bei gleichrangigen normalen Regeln derselben Herkunft und Ebene entscheidet zunächst die Spezifität.

  • Ein einfacher ID-Selektor ist spezifischer als ein einfacher Klassenselektor.
  • Bei gleicher Spezifität entscheidet die spätere Quellreihenfolge.
  • Weitere Kaskadenstufen sind im gesonderten Korrekturverzeichnis verlinkt.
Beispiel lesen
#meldung { color: navy; }
.hinweis { color: red; }

/* Element: id="meldung" class="hinweis" */
Merke / Beobachtung: In dieser eingegrenzten Vergleichssituation ist der Text navy.

Baustein 09 · CSS und Selektoren

Zusammengesetzte Selektoren und Vererbung

p.hinweis verlangt zugleich Elementtyp p und Klasse hinweis. Vererbung übernimmt bestimmte Eigenschaften von Eltern, aber nicht alle.

  • p.hinweis ist keine Liste zweier unabhängiger Selektoren.
  • color kann über einen Elternbereich vererbt werden.
  • Eine passende eigene Deklaration am Kind ist nicht mit geerbtem Wert gleichzusetzen.
Beispiel lesen
article { color: navy; }
p.hinweis { color: darkred; }
Merke / Beobachtung: Der gekennzeichnete Absatz kann eine andere Farbe als der geerbte Grundwert erhalten.
