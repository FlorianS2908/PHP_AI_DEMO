Baustein 07 · Struktur und Navigation

Informationsarchitektur vor Dekoration

Die Unterlage nennt das Ordnen zusammengehöriger Inhalte und eine übersichtliche Aufteilung als Aufgabe der Strukturelemente.

  • Sammle Inhalte und ordne sie dem jeweiligen Zweck zu.
  • Wiederkehrende Navigation und Hauptinhalt sind unterscheidbar.
  • Nicht jede Gruppierung braucht dieselbe Art Container.
Beispiel lesen
Kopf → Navigation → Hauptinhalt → Zusatzinformation → Fuß
Merke / Beobachtung: Zunächst eine inhaltliche Skizze erstellen, erst danach CSS ergänzen.

Baustein 07 · Struktur und Navigation

Header, main und footer

header führt ein, main enthält den zentralen Seiteninhalt und footer ergänzt abschließende Informationen.

  • Unser Seitenmuster hat ein sichtbares main-Element.
  • Eine Suchfunktion kann zum Hauptinhalt einer Suchseite gehören. Das Beispiel ist nach ihrem Zweck zu beurteilen.
  • Quelltextreihenfolge soll den Inhalt nachvollziehbar machen.
Beispiel lesen
<header><h1>EuroCityTravel</h1></header>
<main><h2>Reiseinformationen</h2><p>…</p></main>
<footer><p>Lokale Unterrichtsseite</p></footer>
Merke / Beobachtung: Korrektur K10: main verbietet nicht allgemein Suchfelder, wenn diese den zentralen Inhalt bilden.
Grundlage: PHP-Kurs_Kapitel 4_HTML_Teil 2_Präsentation.pdf · 4–6 · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.
Baustein 07 · Struktur und Navigation

Article, aside und div

article bündelt einen in sich verständlichen Beitrag. aside enthält ergänzende Informationen. div hat keine besondere semantische Bedeutung.

  • Ein Angebot kann ein eigenständiger Beitrag sein.
  • Ein erklärender Hinweis kann ergänzend stehen.
  • Korrektur K10: Ein div ist kein Freibrief für beliebige ungültige Verschachtelung.
Beispiel lesen
<article>
  <h2>Fiktive Städtereise</h2>
  <p>Informationen zum Angebot.</p>
</article>
<aside><h2>Hinweis</h2><p>Keine echte Buchung.</p></aside>
Merke / Beobachtung: Ein Container erhält seine Rolle nicht allein durch seine Position am Bildschirm.
Grundlage: PHP-Kurs_Kapitel 4_HTML_Teil 2_Präsentation.pdf · 7–12 · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.
Baustein 07 · Struktur und Navigation

Navigation mit nav und a

nav bündelt wichtige Navigationslinks. a verweist über href auf ein Ziel.

  • Ein relativer Dateiname verbindet Seiten im selben Ordner.
  • Ein Fragment wie #angebote verweist auf eine ID im Dokument.
  • Nicht jeder einzelne Link muss in einem nav stehen.
Beispiel lesen
<nav aria-label="Hauptnavigation">
  <a href="index.html">Start</a>
  <a href="reisen.html">Reisen</a>
  <a href="kontakt.html">Kontakt</a>
</nav>
Merke / Beobachtung: aria-label ist eine gekennzeichnete Ergänzung für eine verständliche Navigationsbezeichnung.
Grundlage: PHP-Kurs_Kapitel 4_HTML_Teil 2_Präsentation.pdf · 9, 20 · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.
Baustein 07 · Struktur und Navigation

Links und Schaltflächen nicht vermischen

Ein Link führt zu einem Ziel; eine Schaltfläche löst eine Aktion aus. Ein ähnliches Aussehen macht sie nicht semantisch identisch.

  • Korrektur K1: Die a/button-Verschachtelung auf Seite 21 wird nicht als Muster übernommen.
  • Ein Link kann direkt per CSS wie eine Schaltfläche aussehen.
  • Eine Formularübermittlung verwendet eine passende submit-Schaltfläche.
Beispiel lesen
<a class="button-link" href="reisen.html">Reisen ansehen</a>
<button type="submit">Anfrage senden</button>
Merke / Beobachtung: Kein button innerhalb des a-Elements.
Grundlage: PHP-Kurs_Kapitel 4_HTML_Teil 2_Präsentation.pdf · 20–21; K1 · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.
Baustein 07 · Struktur und Navigation

Navigationswege praktisch prüfen

Die Benutzerfreiheit aus Kapitel 3 wird bei Navigation konkret: Menschen sollen sich orientieren und zurückkehren können.

  • Gleiche Funktion überall gleich benennen.
  • Jeder Link benötigt eine existierende Zieldatei beziehungsweise ID.
  • Prüfe auch Tastatur und Browser-Zurück.
Beispiel lesen
Start → Reisen → Kontakt → Start
Merke / Beobachtung: Eine erreichbare Startseite und nachvollziehbare Rückwege gehören zum Test.
