Baustein 01 · User Interfaces

Was ist eine Benutzerschnittstelle?

Eine Benutzerschnittstelle stellt die Verbindung zwischen einer Person und einem System her. Sie ist nicht auf Webseiten beschränkt.

  • Eine Reisende wählt ein Ziel; die Oberfläche zeigt Angebote.
  • Auch ein Fahrkartenautomat oder ein Haushaltsgerät besitzt Bedienelemente.
  • Frage zuerst nach der Handlung der Person und dem erwarteten Ergebnis.
Beispiel lesen
Mensch → Eingabe → System → Ausgabe → Mensch
Merke / Beobachtung: Beispiel: Ziel auswählen → Suche auslösen → Angebote sehen.

Baustein 01 · User Interfaces

Schnittstelle ist nicht gleich Schnittstelle

Die Unterlage unterscheidet mehrere Bedeutungen desselben Wortes. Wir betrachten in PHP vor allem die Mensch-System-Verbindung.

  • User Interface: Mensch und System.
  • Hardware-Schnittstelle: zum Beispiel ein USB-Anschluss.
  • Software-Schnittstelle: zum Beispiel eine API; ein OOP-Interface ist nochmals ein eigener Begriff.
Beispiel lesen
Reiseformular → User Interface
USB-Anschluss → Hardware-Schnittstelle
Datenaustausch zwischen Programmen → Software-Schnittstelle
Merke / Beobachtung: Eine Datenbankverbindung ist nicht automatisch eine Benutzeroberfläche.

Baustein 01 · User Interfaces

Eingabe und Ausgabe auseinanderhalten

Eingaben transportieren Informationen oder Anweisungen zum System. Ausgaben machen Ergebnisse und Zustände für Menschen wahrnehmbar.

  • Maus, Tastatur, Mikrofon oder Sensor liefern Eingaben.
  • Bildschirm, Lautsprecher oder Drucker stellen Ausgaben bereit.
  • Beim Touchscreen können beide Prozesse über dasselbe Gerät stattfinden.
Beispiel lesen
Touchscreen berühren → Eingabe
Ausgewählten Zielort anzeigen → Ausgabe
Merke / Beobachtung: Das gemeinsame Gerät hebt die Unterscheidung der Prozesse nicht auf.

Baustein 01 · User Interfaces

Text, Menü und Grafik

Eine textbasierte Schnittstelle nimmt textuelle Anweisungen entgegen. Menüs zeigen auswählbare Möglichkeiten; eine GUI verwendet grafische Bedienelemente.

  • CLI: Befehle müssen bekannt oder nachgeschlagen werden.
  • Menü: Optionen sind sichtbar, können aber in Untermenüs liegen.
  • GUI: flexible Darstellung und visuelle Rückmeldung; Gestaltung muss durchdacht sein.
Beispiel lesen
CLI-Skizze: suche ziel=Paris
Menü: Reisen → Städte → Paris
GUI: Auswahlfeld „Reiseziel“ + „Angebote suchen“
Merke / Beobachtung: Die CLI-Zeile ist eine Interaktionsskizze, kein echter Systembefehl.

Baustein 01 · User Interfaces

Weitere Arten der Interaktion

Das Kapitel ergänzt Hardware-, Batch-, dialogorientierte, Virtual-Reality- und Brain-Computer-Schnittstellen.

  • Hardware: physische Schalter und Regler. Batch: gebündelte Verarbeitung; die Unterlage nutzt historische Lochkarten als Beispiel.
  • Conversational: menschliche Sprache als Text oder Ton.
  • VR und Brain-Computer werden als weitere Kategorien vorgestellt; Aussagen zum damaligen Entwicklungsstand sind keine aktuellen Marktangaben.
Merke / Beobachtung: Welcher Typ passt zur Aufgabe – und welche Voraussetzungen setzt er voraus?

Baustein 01 · User Interfaces

Nicht pauschal bewerten, sondern begründen

Die Unterlage fordert den Vergleich von CLI, Menü, GUI und Dialog. Schnittstellentypen können kombiniert werden.

  • Beschreibe Zielgruppe, Tätigkeit und verfügbare Geräte.
  • Formuliere einen Vorteil und eine konkrete Schwierigkeit.
  • Eine GUI kann zugleich ein Menü und eine Spracheingabe anbieten.
Beispiel lesen
Situation: Eine unerfahrene Person möchte genau ein Ziel auswählen.
Entwurf: Sichtbare Auswahl und klar beschriftete Suchaktion.
Merke / Beobachtung: Begründung: Die zulässigen Möglichkeiten sind erkennbar; keine Befehlssyntax muss erinnert werden.
