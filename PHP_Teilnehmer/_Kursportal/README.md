# Hintergrund des Kursportals

Diese Dateien betreiben und ergänzen die Kursansicht. Einstieg für den Unterricht: [Kursübersicht](../index.html).

| Bereich | Zweck |
| --- | --- |
| assets | Gemeinsame Gestaltung, Skripte und Medien |
| module | Webvarianten und fachliche Erklärungen im Themenfundus |
| backend | PHP-Empfänger und ausführbare Lehrbeispiele |
| optional | Ausgelagerter Datenbankbaustein und Anschlussmaterial |
| materialien.html | Thematische Navigation zu allen Bausteinen |
| quellen.html | Quellen und Fachkorrekturen |
| manifest.json | Dateiinventar; Pfade relativ zum übergeordneten Rollenordner |

In der Dozentenfassung zusätzlich: Kursdaten, historische Prüfberichte und ergänzende Hinweise. Alles zusammen mit dem Kurs kopieren. Die Bündelung dient der Orientierung, nicht einer Zugriffssperre.
