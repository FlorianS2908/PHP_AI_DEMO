Kurz erklärt

Speichere die Datei mit der Endung .php und rufe sie über http://localhost/... auf. Ein Doppelklick führt PHP nicht aus. Beginne mit festen Werten; Formulardaten kommen als eigener Schritt an Tag 4.

Bei Schleifen immer Startwert, Bedingung, Veränderung und Ausgabe notieren. Nutze zunächst if/else, for und foreach. switch, while und do-while liegen als kurze Vertiefung im vorhandenen Baustein 11 bereit.

PHP-Tag
<?php beginnt PHP-Code. ?> beendet den PHP-Bereich, wenn HTML folgt. In reinen PHP-Dateien lassen wir den schließenden Tag weg, damit nicht versehentlich Leerraum ausgegeben wird.
DOCTYPE und PHP
DOCTYPE betrifft das HTML-Dokument für den Browser. PHP-Tags betreffen die Verarbeitung auf dem Server. Der Browser erhält das Ergebnis, nicht den ausführbaren PHP-Quellcode.
Variable und Typ
Eine Variable beginnt mit $. Werte haben Typen, etwa int, float, string, bool oder array. PHP ist dynamisch typisiert: eine gewöhnliche Variable kann nacheinander Werte verschiedener Typen halten.
Statisch und dynamisch
Statische Typisierung prüft Typbeziehungen weitgehend vor der Ausführung. Dynamische Typisierung bestimmt bzw. prüft sie zur Laufzeit. Das ist eine andere Frage als die nach erlaubten automatischen Umwandlungen.
Streng und weniger streng
Mit stark oder schwach typisiert ist meist gemeint, wie streng eine Sprache mit Typmischungen umgeht. Die Begriffe sind nicht einheitlich definiert. PHP erlaubt in manchen Situationen implizite Typumwandlung; Eingaben müssen trotzdem bewusst geprüft werden.
declare(strict_types=1)
Als erste PHP-Anweisung schaltet es für diese Datei strenge Regeln bei skalaren Typdeklarationen ein. Bei eigenen Funktionsaufrufen bestimmt die aufrufende Datei die Argumentprüfung. Rückgabewerte werden an der Funktionsdefinition geprüft. int ist für einen float-Parameter weiterhin erlaubt. Gewöhnliche Variablen werden dadurch nicht statisch typisiert.
=, == und ===
= weist zu; == vergleicht nach den PHP-Vergleichsregeln mit möglichen Typumwandlungen; === vergleicht Wert und Typ. Der String "3" ist nicht identisch mit der Zahl 3.
Kontrollstruktur und Funktion
if wählt einen Weg. for und foreach wiederholen Schritte. Eine Funktion bündelt eine Aufgabe; Parameter sind Eingaben und return liefert ein Ergebnis. HTML-Attribute sind keine PHP-Variablen; PHP-Attribute als Metadaten sind kein Kursthema.

Kleines Beispiel lesen

<?php
declare(strict_types=1);
function doppelt(int $zahl): int {
    return $zahl * 2;
}
$anzahl = 3;
$summe = doppelt($anzahl);
?>
<!doctype html>
<html lang="de">
<head><meta charset="utf-8"><title>PHP-Einstieg</title></head>
<body><p>Ergebnis: <?= $summe ?></p></body>
</html>

Erst die Wirkung vorhersagen, dann ausführen oder im Browser untersuchen. Das Beispiel erklärt ein Prinzip; es ist keine Lösung der folgenden Aufgabe.

Selbst umsetzen

Bearbeite die TODOs in der Startdatei: Lege drei Lernziele in einem Array ab, gib sie mit foreach aus und ergänze eine Entscheidung zur Teilnehmerzahl. Schreibe eine Funktion für eine einfache Berechnung. Notiere die erwartete Ausgabe vor dem Aufruf. Erkläre anschließend "3" === 3 und die Wirkung von strict_types am Funktionsaufruf.

Abgabe: eigene Dateien, kurze Erklärung und mindestens ein Normal-, Fehl- und Grenzfall mit Soll/Ist-Vergleich.
