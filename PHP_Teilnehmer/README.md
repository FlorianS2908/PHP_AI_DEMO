## Im Hintergrund

`_Kursportal` bündelt Webmodule, Backend, Gestaltung, Quellen, Metadaten und ergänzendes Material. Diese Dateien bleiben für das Kursportal erforderlich. Den Ordner mitkopieren; im Unterricht genügt die Navigation.

Arbeitskopien gehören in [Persoenliche_Arbeit](../PHP_Arbeitsbereich/Persoenliche_Arbeit/README.md).
