Kurz erklärt

Starte mit einem Nutzerziel: Eine Person möchte den Beginn eines Workshops finden. Gliedere die Information mit header, nav, main und footer. Überschriften ordnen Inhalte, CSS gestaltet sie. Eine Schnittstelle liefert nach einer Eingabe eine verständliche Rückmeldung.

Prüfe mit Maus und Tastatur: Erreiche ich jeden Link mit Tab? Sehe ich den Fokus? Ist der Linktext verständlich? Vergrößere die Seite auf 200 Prozent. Informationen dürfen nicht allein durch Farbe vermittelt werden.

Schnittstelle
Ein definierter Übergang, über den Eingaben und Ausgaben ausgetauscht werden. Eine Benutzeroberfläche verbindet Mensch und Software; HTTP verbindet Browser und Server.
Peripheriegerät
Ein Ein- oder Ausgabegerät, etwa Tastatur, Maus, Mikrofon, Bildschirm oder Drucker. Ein Touchscreen kann beides. Hardware und Softwareoberfläche sind unterschiedliche Ebenen der Interaktion.
UI, Usability und UX
UI ist die bedienbare Oberfläche. Usability beschreibt, wie gut eine Person ihr Ziel erreicht. UX umfasst das gesamte Nutzungserlebnis, etwa Orientierung und Vertrauen.
DOCTYPE und Dokument
<!doctype html> fordert den Standardmodus des Browsers an. Es ist eine Dokumenttyp-Deklaration, kein sichtbares HTML-Element. html umschließt das Dokument, head enthält Metadaten, body die Seiteninhalte.
Tag, Element und Attribut
<p> ist ein Start-Tag; <p>Hallo</p> ist ein Element. Attribute stehen im Start-Tag, etwa lang="de" oder href="ziel.html". input ist ein leeres Element ohne End-Tag.
id und class
id kennzeichnet ein Element eindeutig innerhalb einer Seite. class ordnet ein oder mehrere Elemente einer wiederverwendbaren CSS-Klasse zu. Diese Klasse ist keine OOP-Klasse.
CSS-Regel
In .hinweis { color: navy; } ist .hinweis der Selektor, color die Eigenschaft und navy der Wert. Eigenschaft und Wert bilden eine Deklaration. Eine Datei wird über link rel="stylesheet" eingebunden.
Kaskade und Box-Modell
Bei konkurrierenden Regeln entscheiden unter anderem Spezifität und Reihenfolge. Inhalt, Innenabstand (padding), Rahmen und Außenabstand (margin) bestimmen die Box.

Kleines Beispiel lesen

<!doctype html>
<html lang="de">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Workshop</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main id="inhalt">
    <h1>Unser Workshop</h1>
    <p class="hinweis">Beginn: 09:00 Uhr</p>
    <a href="#inhalt">Zur Übersicht</a>
  </main>
</body>
</html>

Erst die Wirkung vorhersagen, dann ausführen oder im Browser untersuchen. Das Beispiel erklärt ein Prinzip; es ist keine Lösung der folgenden Aufgabe.

Selbst umsetzen

Erstelle eine Seite mit Hauptüberschrift, zwei Abschnitten, einer Liste und zwei Navigationslinks. Verwende eine CSS-Klasse mehrfach und eine id nur einmal. Ergänze Abstände und einen sichtbaren Fokus. Nutze das HTML-Tag-Tool, um zwei Attribute nachzuschlagen. Notiere drei Beobachtungen zu Tastaturbedienung und Lesbarkeit.

Abgabe: eigene Dateien, kurze Erklärung und mindestens ein Normal-, Fehl- und Grenzfall mit Soll/Ist-Vergleich.

Wissenscheck

  • Erkläre am eigenen Code den Unterschied zwischen Tag, Element und Attribut.
  • Zeige eine CSS-Regel und benenne Selektor, Eigenschaft und Wert.
  • Ordne Tastatur, Bildschirm und HTTP den passenden Schnittstellenebenen zu.

Hinweise für die Lehrkraft

HTML und CSS bereits am Vormittag schreiben lassen. UI/UX als konkreten Prüfauftrag integrieren, nicht als langen Theorieblock. Fokus, Semantik und lesbare Namen vor aufwendigen Layouts behandeln.
