Baustein 05 · HTML-Grundlagen

Grundgerüst einer HTML-Datei

Ein Dokument trennt Metainformationen im head vom sichtbaren Inhalt im body. Die Struktur wird durch Elemente ausgezeichnet.

  • Speichere als index.html und mit UTF-8.
  • title beschreibt den Dokumenttitel, h1 eine sichtbare Hauptüberschrift.
  • Einrückung hilft beim Lesen der Verschachtelung.
Beispiel lesen
<!doctype html>
<html lang="de">
<head>
  <meta charset="utf-8">
  <title>Reiseplanung</title>
</head>
<body>
  <h1>Meine Reiseplanung</h1>
</body>
</html>
Merke / Beobachtung: Vergleiche Titel im Browser-Tab und Überschrift auf der Seite.

Baustein 05 · HTML-Grundlagen

Element, Tag und Inhalt

Bei einem Container stehen Inhalte zwischen Start- und End-Tag. Leere Elemente wie br oder img haben keinen solchen Inhaltsbereich.

  • Der Schrägstrich kennzeichnet das End-Tag eines Containers.
  • Korrektur K6: Bei leeren Elementen in HTML ist der abschließende Schrägstrich nicht erforderlich.
  • Die Beispiele nutzen vollständige End-Tags bei Containern, damit die Struktur sichtbar bleibt.
Beispiel lesen
<p>Ein Absatz mit <strong>wichtiger Information</strong>.</p>
<br>
<img src="bild.svg" alt="Beschriebene Beispielgrafik">
Merke / Beobachtung: strong liegt innerhalb des Absatzes; das Bild besitzt kein schließendes img-Tag.

Verschachtelung und Semantik

HTML beschreibt die Bedeutung und Beziehung von Inhalten. Wähle das Element nach seinem Zweck, nicht nach einer zufälligen Standarddarstellung.

  • Ein Absatz bleibt ein Absatz, auch wenn CSS ihn groß darstellt.
  • Eine Überschrift erhält ein Überschriftenelement.
  • Nicht jedes Element darf beliebige andere Elemente enthalten.
Beispiel lesen
<article>
  <h2>Reiseinformationen</h2>
  <p>Die Informationen stehen in einem Absatz.</p>
</article>
Merke / Beobachtung: Die innere Struktur wird vor dem äußeren Container geschlossen.

Attribute, IDs und Klassen

Attribute ergänzen ein Element. Eine ID identifiziert es im Dokument; eine Klasse fasst mehrere Elemente zur gemeinsamen Ansprache zusammen.

  • Attribute stehen im Start-Tag.
  • Mehrere Elemente können dieselbe Klasse besitzen, IDs bleiben eindeutig.
  • Korrektur K7: Der Kurs beginnt Bezeichner mit Buchstaben als einfache Konvention, nicht als allgemeines HTML-Verbot für Ziffern.
Beispiel lesen
<p id="hinweis-a" class="hinweis">Erster Hinweis</p>
<p id="hinweis-b" class="hinweis">Zweiter Hinweis</p>
Merke / Beobachtung: Zwei IDs, eine gemeinsame Klasse.

Kommentare und Zeichencodierung

Kommentare erläutern den Quelltext. UTF-8 sorgt zusammen mit korrekt gespeicherten Dateien dafür, dass beispielsweise Umlaute lesbar sind.

  • Kommentare erscheinen nicht als normaler Seiteninhalt.
  • Korrektur K8: Der Tippfehler „UFT-8“ wird als UTF-8 geschrieben.
  • Öffne nach Änderungen die gespeicherte Datei erneut beziehungsweise lade sie neu.
Beispiel lesen
<!-- Hier beginnen die Reiseinformationen. -->
<meta charset="utf-8">
Merke / Beobachtung: Die meta-Angabe gehört in den head.

Baustein 05 · HTML-Grundlagen

Datei, Darstellung und DOM unterscheiden

Der Browser liest das Dokument und bildet daraus eine Dokumentstruktur im Speicher. CSS gestaltet ihre Darstellung.

  • Quelltext und Bildschirmdarstellung sind unterschiedliche Ansichten derselben Seite.
  • Korrektur K9 zur DOM-Folie: PHP läuft in unserem Kurs serverseitig; Änderungen am lebenden Browser-DOM sind nicht unmittelbar PHP-Ausführung.
  • Nutze im Browser „Seitenquelltext anzeigen“ und die Entwicklerwerkzeuge zum Vergleichen.
Beispiel lesen
Datei → Browser liest HTML → Dokumentstruktur → Darstellung
Merke / Beobachtung: Der Browser kann ungünstiges HTML teilweise reparieren. Eine sichtbare Seite beweist deshalb nicht fehlerfreien Quelltext.
