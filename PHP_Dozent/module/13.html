Inhalt, padding, border und margin

Das Box-Modell unterscheidet Inhalt, Innenabstand, Rahmen und Außenabstand.

  • padding liegt zwischen Inhalt und Rahmen.
  • margin liegt außerhalb des Rahmens.
  • Bei box-sizing: border-box werden Innenabstand und Rahmen in eine gesetzte Breite einbezogen.
Beispiel lesen
.karte {
  box-sizing: border-box;
  width: 280px;
  padding: 20px;
  border: 2px solid navy;
  margin: 16px;
}
Merke / Beobachtung: Margin gehört weiterhin nicht zur gesetzten Boxbreite.
Grundlage: Webgrundlagen_tag_01_Webvariante_erweitert.html · Box-Modell · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.

Werte und Einheiten gezielt wählen

Die Referenz betrachtet px, rem und relative Werte. Der Bezug eines Wertes hängt von der Eigenschaft ab.

  • rem bei Schriftgrößen bezieht sich auf das Wurzelelement.
  • Prozentangaben benötigen einen jeweiligen Bezugswert.
  • Vermeide starre Breiten, die kleine Ansichten ohne Grund überlaufen lassen.
Beispiel lesen
body { font-size: 1rem; }
.inhalt { width: 90%; max-width: 1000px; }
Merke / Beobachtung: Im Browser die tatsächliche Größe prüfen, statt sie aus dem Wert zu erraten.

Wiederkehrende Werte benennen

Custom Properties speichern wiederverwendbare Gestaltungswerte. var liest sie aus.

  • Der Name beginnt mit zwei Bindestrichen.
  • Eine gemeinsame Definition vermeidet abweichende Einzelwerte.
  • Namen sollten die Rolle erklären.
Beispiel lesen
:root { --akzent: #0074c8; }
.karte { border-color: var(--akzent); }
.navigation a { color: var(--akzent); }
Merke / Beobachtung: Eine Änderung an --akzent betrifft beide Regeln.
Grundlage: Webgrundlagen_tag_01_Webvariante_erweitert.html · CSS Custom Properties · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.

Layout mit Flexbox und Umbruch

Als gekennzeichnete didaktische Ausarbeitung der Layout-Grundlagen verwenden wir eine kleine Flex-Navigation.

  • Der Container erhält display: flex.
  • gap hält Abstände zwischen Elementen.
  • flex-wrap erlaubt Umbruch, statt Links aus dem Fenster zu schieben.
Beispiel lesen
.navigation {
  display: flex;
  gap: 1rem;
  flex-wrap: wrap;
}
Merke / Beobachtung: Für den Einstieg zuerst Container und seine unmittelbaren Kinder identifizieren.
Grundlage: Webgrundlagen_tag_01_Webvariante_erweitert.html · Layout-Grundlagen; ergänzende Ausarbeitung · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.

Mit Browserwerkzeugen überprüfen

Die Referenz verwendet DevTools, um angewendete Regeln, Überschreibungen und Größen zu untersuchen.

  • Prüfe eine breite und eine schmale Ansicht.
  • Gehe interaktive Elemente mit Tab durch und beobachte den Fokus.
  • Ändere für Experimente immer nur eine Eigenschaft und vergleiche.
Beispiel lesen
a:focus-visible {
  outline: 3px solid #b44f00;
  outline-offset: 3px;
}
Merke / Beobachtung: Fokusgestaltung ist hier eine gekennzeichnete Bedienbarkeits-Ergänzung.
Grundlage: Webgrundlagen_tag_01_Webvariante_erweitert.html · DevTools; ergänzender Fokuscheck · Beispiele und Arbeitsaufträge didaktisch neu ausgearbeitet; Korrekturen gesondert gekennzeichnet.
