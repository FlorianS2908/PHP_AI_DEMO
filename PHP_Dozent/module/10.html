Baustein 10 · Farben und Hintergründe

Farbwerte ausdrücken

Die Unterlage zeigt Farbnamen sowie RGB-, HEX- und HSL-Schreibweisen. Text- und Hintergrundfarbe werden getrennt eingestellt.

  • color gestaltet Text.
  • background-color gestaltet den Hintergrund.
  • Eine kleine konsistent eingesetzte Palette erleichtert ein gemeinsames Design.
Beispiel lesen
.hinweis {
  color: #0b1b4d;
  background-color: rgb(234, 247, 251);
}
Merke / Beobachtung: Die verwendeten Farben sind Kursbeispiele, keine allgemeingültige Markenpalette.

Baustein 10 · Farben und Hintergründe

Alpha und opacity unterscheiden

Ein Alpha-Wert gehört zur jeweiligen Farbe. opacity wirkt auf die Darstellung des gesamten Elements einschließlich seines Inhalts.

  • Alpha 0 ist transparent; 1 ist deckend.
  • Ein halbtransparenter Hintergrund muss den Text nicht halbtransparent machen.
  • Vergleiche beide Varianten vor demselben Hintergrund.
Beispiel lesen
.nur-hintergrund { background: rgba(0, 116, 200, .25); }
.ganzes-element { background: rgb(0, 116, 200); opacity: .25; }
Merke / Beobachtung: In der zweiten Variante wird auch der Text mit abgeschwächt.

Baustein 10 · Farben und Hintergründe

Hintergrundbild und Wiederholung

background-image nutzt eine URL. Relative Pfade in einer CSS-Datei beziehen sich auf diese CSS-Datei.

  • repeat wiederholt, no-repeat zeigt das Bild einmal.
  • repeat-x und repeat-y beschränken die Wiederholungsrichtung.
  • background-position richtet es aus, beispielsweise center top.
Beispiel lesen
.flaeche {
  background-image: url("../../assets/beispiel.svg");
  background-repeat: no-repeat;
  background-position: center;
}
Merke / Beobachtung: Anders als img trägt ein reines Hintergrundbild keinen eigenen alt-Text.

Cover und contain vergleichen

Korrektur K3: cover erhält bei Bildern mit natürlichem Seitenverhältnis dieses Verhältnis und kann Teile abschneiden. contain hält das ganze Bild im Bereich.

  • cover: Fläche gefüllt, Bildausschnitt eventuell beschnitten.
  • contain: vollständiges Bild, freie Fläche möglich.
  • Die Demo verwendet dasselbe Bild und denselben Rahmen für beide Fälle.
Beispiel lesen
.cover { background-size: cover; }
.contain { background-size: contain; }
Merke / Beobachtung: Cover verzerrt die Kreisform der Beispielgrafik nicht.

Drei Arten von Verläufen

Lineare Verläufe gehen entlang einer Richtung, radiale vom Zentrum nach außen und konische um das Zentrum herum.

  • Die Verläufe werden als background-image eingesetzt.
  • Farbstopps steuern die Übergänge.
  • Gestalterische Effekte dürfen den Vordergrund nicht unlesbar machen.
Beispiel lesen
.linear { background-image: linear-gradient(to right, navy, skyblue); }
.radial { background-image: radial-gradient(circle, white, navy); }
.konisch { background-image: conic-gradient(navy, skyblue, navy); }
Merke / Beobachtung: Die drei Flächen sind in Demo 2 unmittelbar vergleichbar.

Baustein 10 · Farben und Hintergründe

Farbwirkung und Farbschema

Die Unterlage verbindet Farben mit kulturell geprägten Assoziationen und stellt monochromatische, komplementäre, analoge und triadische Schemata vor.

  • Die Farbwirkung ist keine Garantie für die Reaktion jeder Person.
  • Lege Rollen für Grundfarbe, Hintergrund, Text und Akzent fest.
  • Informationen nicht ausschließlich von einer Farbe abhängig machen.
Beispiel lesen
Monochromatisch: ein Farbton in Varianten.
Komplementär: gegenüberliegende Farbtöne.
Analog: benachbarte Farbtöne.
Triadisch: drei gleichmäßig verteilte Farbtöne.
Merke / Beobachtung: Benennung und Erklärung folgen der Unterlage; keine pauschalen psychologischen Versprechen.
