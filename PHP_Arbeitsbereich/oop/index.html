01 / Grundidee

Vier Begriffe reichen für den Start.

Klasse und Objekt

Klasse: gemeinsamer Bauplan, etwa Tasse.
Objekt: eine konkrete Tasse, zum Beispiel die rote.

Attribut und Methode

Attribut: ein Wert des Objekts, etwa seine Farbe.
Methode: eine Funktion der Klasse, etwa die Farbe ändern.

Begrifflicher Anschluss: Java-OO, PDF-Seiten 9–11. In PHP werden Attribute im Handbuch auch „Eigenschaften“ genannt. [1] [2]

02 / PHP-Syntax

Ein vollständiges kleines Beispiel

class Tasse
{
    public $farbe = "";

    public function __construct($farbe)
    {
        $this->farbe = $farbe;
    }

    public function getText()
    {
        return "Tasse: " . $this->farbe;
    }
}

$tasse = new Tasse("rot");
echo $tasse->getText();

Ausgabe: Tasse: rot

SchreibweiseBedeutung in diesem Beispiel
class Tasse { ... }Hier steht die Klassendefinition.
public $farbeEin öffentlich zugängliches Attribut wird deklariert.
new Tasse("rot")Ein Objekt wird mit einem Startwert erzeugt.
__construct($farbe)Der Konstruktor läuft beim Erzeugen. In PHP heißt er __construct – anders als in den Java-Beispielen.
$this->farbe = $farbe;Links: Attribut dieses Objekts. Rechts: Parameter des Aufrufs.
$tasse->getText()Eine Methode des konkreten Objekts aufrufen. Die Klammern gehören zum Aufruf.
return / echoreturn liefert den Wert zurück; echo gibt ihn aus.

Bei einem festen Attributnamen steht nach dem Pfeil kein weiteres Dollarzeichen: $this->farbe. Das Attribut wird in der Klasse dagegen mit $farbe deklariert.

Neue PHP-Übertragung, technische Referenzen [1]–[5]. Die Klassendefinition selbst startet keine HTML-Ausgabe.

04 / public und private

Später steuert die Klasse den Zugriff.

Aufgaben 1–6 verwenden öffentliche Attribute zum Kennenlernen der Schreibweise. Ab Aufgabe 7 werden die Daten gekapselt: ein privates Attribut, dazu öffentliche Methoden.

private $farbe = "rot";

public function getFarbe()
{
    return $this->farbe;
}

Ausschnitt innerhalb einer Klasse: ein privates Attribut und ein öffentlicher Getter.

Getter: liest einen Wert.
Setter: verändert einen Wert; dort kann eine Gültigkeitsprüfung stehen.

In Aufgabe 8 liefert der Setter true oder false. Bei ungültigen Werten bleibt der alte Zustand erhalten. Das ist unsere Übungsregel, keine vorgeschriebene PHP-Signatur für alle Setter.

private begrenzt den Zugriff im Programmcode. Es ersetzt keine Eingabeprüfung. Die Quelle zur Kapselung ist Java-OO, Seiten 15–16 und gedruckte Folie 62; die PHP-Sichtbarkeit steht in [4].

05 / Anschluss an eure Formulare

Formular und Klasse haben verschiedene Aufgaben.

POST empfangen und prüfen
→ bei Fehlern: Meldung + gültige Eingaben zurückgeben
→ bei Erfolg: new Lagerartikel(...)
→ geprüften Bestand über die Methode setzen
→ Werte über Getter für HTML auslesen

auswertung.php kennt $_POST und die Rückleitung.
Lagerartikel.php enthält Attribute und Methoden, aber kein HTML und kein $_POST.
index.php zeigt das Formular; function.php enthält den bekannten HTML-Helper.

Die sichtbaren Prüfungen mit isset(), Texttyp und erlaubten Inhalten sind in der letzten Aufgabe bereits vorbereitet. Neu ergänzt ihr dort nur die OOP-Stellen.

In diesem Paket werden keine Objekte dauerhaft gespeichert. Die PHP-Beispiele erzeugen sie bei jedem Aufruf neu. Sessions und Datenbank werden nicht zusätzlich eingebaut.

Eigene kleine Dateiaufteilung zum Üben, noch keine vollständige MVC-Anwendung. Das vorhandene Formularmaterial liefert den bekannten Ablauf; PHP-Referenzen [6] und [7].
