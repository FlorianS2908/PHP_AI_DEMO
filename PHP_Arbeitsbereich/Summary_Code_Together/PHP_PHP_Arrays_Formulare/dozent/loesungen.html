Aufgabe 4

Pseudocode in eine Preisfunktion übersetzen

Der Rechenweg ist pro Person 19900 + 2500 + 1800 + 1200 bzw. + 3000. Mit zwei Personen entstehen die genannten Summen.

Muster / gezielte Ergänzung
function gesamtCent(array $reise, array $ziele, array $extras, array $verpflegungen): int
{
    $summe = $ziele[$reise['ziel']]['preis_cent'];
    foreach ($reise['extras'] as $id) {
        $summe += $extras[$id]['preis_cent'];
    }
    $summe += $verpflegungen[$reise['verpflegung']]['preis_cent'];
    return $summe * $reise['personen'];
}
