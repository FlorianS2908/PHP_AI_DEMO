Was du anschließend erklären kannst

  • Indexierte, assoziative und verschachtelte Arrays lesen, verändern und durchlaufen.
  • Passende Kontrollstrukturen auswählen und einen Ablauf zunächst in Pseudocode beschreiben.
  • Einfach- und Mehrfachauswahl aus einem Katalog erzeugen und als benannte Struktur absenden.
  • Werte zwischen mehreren Seiten weitergeben, erneut prüfen und formatiert ausgeben.
  • Begründen, warum wir später einen Mechanismus zum Merken von Zuständen brauchen.
Arbeitsweise: erst Code lesen, dann Ausgabe vorhersagen, dann ausführen. Keine eigenen Klassen, keine Datenbank, keine Anmeldung.

Schlüssel oder Wert gesucht?

PHP

Kontrollstrukturen

while und do-while: Zeitpunkt der Prüfung

while · Bedingung zuerst
$i = 5;
while ($i < 3) {
    echo $i;
    $i++;
}
// keine Ausgabe
do-while · Rumpf zuerst
$i = 5;
do {
    echo $i;
    $i++;
} while ($i < 3);
// Ausgabe: 5
Beide sind gültige Schleifenformen. Für eine bereits vorhandene Auswahl-Liste ist hier foreach am direktesten. Wir verwenden nicht jede Schleife künstlich im Formularprozess.

continue und break unterscheiden

Zuerst Pseudocode: Preise sammeln

Pseudocode · didaktische Schreibweise, kein PHP
VORAUSSETZUNG: Auswahl wurde geprüft
preisProPerson ← Zielkatalog[auswahl.ziel].preisCent

FÜR JEDES extraId IN auswahl.extras
    preisProPerson ← preisProPerson + Extrakatalog[extraId].preisCent
ENDE FÜR

preisProPerson ← preisProPerson + Verpflegungskatalog[auswahl.verpflegung].preisCent
gesamtCent ← preisProPerson × auswahl.personen
GIB gesamtCent ZURÜCK
Fiktive Rechenregel: Jede Position kostet einmalig pro Person. Es gibt in dieser Demo keine Nächte, Steuern oder Rabatte. Diese Regeln nicht hineininterpretieren.

Formulare

HTML-number ist noch kein PHP-Integer

Ausschnitt · vollständige Prüfung im Demo
$roh = $_POST['reise']['personen'] ?? null;
if (!is_string($roh)) {
    // fehlender Wert oder manipuliertes Array → Fehler
} else {
    $personen = filter_var($roh, FILTER_VALIDATE_INT, [
        'options' => ['min_range' => 1, 'max_range' => 6],
    ]);
    if ($personen === false) { /* Fehler anzeigen */ }
}
Auch Zahlenfelder und numerische option-Werte kommen in diesem Formular als Strings an. Vor Rechnen oder Vergleichen erst Form und Wertebereich prüfen. Die vollständige Funktion sammelt Fehler in einem Array.

        $text,
        ENT_QUOTES | ENT_SUBSTITUTE,
        'UTF-8'
    );
}

Session-Ausblick

Nächster Schritt: Session statt Hidden-Kette

Konzeptbeispiel · noch kein vollständiger Session-Workflow
// NUR AUSBLICK – nicht im ausführbaren Hauptdemo verwendet.
// Vor jeglicher HTML-Ausgabe:
session_start();

// Nach erfolgreicher Prüfung:
$_SESSION['reise'] = $reise;

$reise = $_SESSION['reise'] ?? null;
Dann brauchen die bisherigen Auswahlwerte nicht in jedem Formular wiederholt zu werden. Serverkonfiguration, Lebensdauer, Session-ID-Schutz und Berechtigungen werden im nächsten Baustein behandelt.

Session-Ausblick

Nächster Schritt: kleine Einstellungen als Cookie

  • Geeigneter erster Lernfall: eine unkritische Darstellungspräferenz, etwa ein gewähltes Farbschema.
  • Der Server setzt das Cookie über einen Antwort-Header; ein späterer Request kann es zurückbringen.
  • setcookie() muss vor der HTML-Ausgabe aufgerufen werden.
  • Ein Cookie ist vom Client beeinflussbar: Preis, Berechtigung oder Identität nicht ungeprüft daraus ableiten.
Heute werden weder Cookies gesetzt noch Sessions gestartet. Zuerst soll sichtbar werden, welches Problem diese Mechanismen später lösen.

Was jetzt sitzen sollte

  • Ein PHP-Array ordnet Werte zu Schlüsseln; Werte können weitere Arrays sein.
  • Die Arraynotation in Formularnamen bestimmt die von PHP gelesene Struktur.
  • Ein neues Formular braucht alle weiterzugebenden Werte ausdrücklich erneut.
  • Katalogdaten bleiben auf dem Server; Auswahlwerte werden pro Request geprüft.
  • PHP erzeugt eine neue HTML-Antwort; Textarea und gestalteter HTML-Bereich sind verschiedene Ausgabeformen.
  • Sessions und Cookies beantworten die nächste Frage: Wie bleibt Zustand ohne dauerndes Mitsenden verfügbar?
