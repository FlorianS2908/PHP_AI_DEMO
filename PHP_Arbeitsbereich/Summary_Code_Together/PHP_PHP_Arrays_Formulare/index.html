Einmal entpacken, direkt starten

Nur die Folien: START-Webvariante.cmd oder webvariante.html öffnen.

Die echten PHP-Demos: PHP-START.cmd starten. Das Fenster offen lassen und danach http://127.0.0.1:8080/ im Browser öffnen. Vorhandenes PHP bzw. XAMPP genügt. MySQL wird nicht gebraucht.

Alternativ im Terminal: php -d session.auto_start=0 -S 127.0.0.1:8080 -t . im entpackten Paketordner.
