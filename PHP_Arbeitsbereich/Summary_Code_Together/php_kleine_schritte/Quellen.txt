Neue, vereinfachte Übungsreihe auf Wunsch der Lehrkraft.
Keine wörtliche Übernahme einer bestehenden Aufgabenserie.
Grundlage: PHP-Kurs, Kapitel 6 PHP DB, Seiten 17–21
(Kontrollstrukturen, Arrayfunktionen, Formularauswertung).
HTML-Bezug: Kapitel 4, HTML Teil 2, Seiten 23–30
(form/action/method, Eingabetypen, Checkbox und select).
Zusätzliche Grundlage: PHP_PHP_Arrays_Formulare_Webvariante.html.

Vereinfachung gegenüber der Mehrseiten-Demo: nur vier flache Felder,
keine verschachtelten Arrays, keine Extras-Listen, keine Speicherung.
Die HTML-Ausgabemaskierung und kleine vorbereitete Typprüfungen sind
technische Hilfen; die Aufgaben konzentrieren sich auf den PHP-Block.

isset ist kein Leertext-Test: bei leerem String ist das Ergebnis true.
empty behandelt unter anderem auch den String "0" als leer. Deshalb wird
hier leere Texteingabe nach Typprüfung mit trim($text) === "" geprüft.
Die spätere Rückkehr zum Formular verwendet wieder die Standardwerte.
