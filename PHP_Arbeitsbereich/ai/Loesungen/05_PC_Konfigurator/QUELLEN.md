# Fachliche Quellen

- [Q1] PHP-Handbuch: Formulare verarbeiten: https://www.php.net/manual/de/tutorial.forms.php

- [Q3] W3C WAI: User Notifications bei Formularen: https://www.w3.org/WAI/tutorials/forms/notifications/
- [Q4] MDN: CSS Grid Layout: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout
- [Q5] OWASP: LLM Prompt Injection Prevention Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html
- [Q6] PHP-Handbuch: htmlspecialchars und HTML-Ausgabe: https://www.php.net/manual/de/function.htmlspecialchars.php
- [Q7] PHP-Handbuch: empty und die Bedeutung von „leer“: https://www.php.net/manual/de/function.empty.php
- [Q8] MDN: Client-side form validation und Serverprüfung: https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation
